# ローカルCodexへの引き継ぎ

## 最初に行うこと

ユーザーは、大きくてチャットに送れない参考APKをローカルで確認して、PetGame / MofumofuのUIと犬のモーションの品質をさらに高めたい。

参考APKの手掛かりは **StarDeskにある `IllusttChi2`**。これはユーザーの表記そのままで、正確なファイル名・絶対パスは未確認。クラウド側の `/workspace`、`/tmp`、`/mnt`、`/home` では見つからず、APKの内容は一切確認できていない。ユーザーのローカル環境で、まずStarDeskとその下のAPK・関連フォルダを探す。表記揺れや拡張子も確認する。ローカルに存在するものをチャットへ再アップロードする必要はない。

APKは元ファイルを保持し、作業用ディレクトリで内容を確認する。ZIP構造、manifest、assets、画像、アニメーション情報、使用エンジンを調べ、使用可能なエミュレーターや実機があれば実際の画面・動きも確認する。静的な素材調査と実際の再生確認は区別する。見ていない画面や動きを推測で確認済みにしない。

参考から、画面構成、タッチ反応、表情の切り替わり、動作の間、首・耳・しっぽ・胴体の連動などを具体的に整理し、現在のMofumofuと比較して改善を実装する。採用済み犬の絵柄を置き換えるのではなく、独自キャラクターの動きとゲーム体験に反映する。

## ユーザーの進め方の希望

- 途中の進捗報告や「続けますか？」の確認をしない。
- 追加の指示を待たず、自分で実行・見た目を確認し、問題があれば修正して一まとまりの成果まで完成させる。
- ユーザーの明示的許可なくサブエージェントを使わない。
- UIと物語は仮なので、以下のコンセプトに従って品質を上げてよい。犬のモーションも引き続き開発する。
- 元素材やローカルのユーザー変更を保持する。公開へのマージ・デプロイは今回まだ実施していない。

## コンセプトと維持事項

Android / iPhone向け縦画面PWAのペット育成ゲーム。近未来SFの小さな部屋で、災害後の静かな終末世界を犬と暮らす。温もりのあるアニメ調。画面に人間を描かない。猫は採用済みだが、現在の開発対象は犬。

犬はボーダーコリー風のオリジナルキャラクター。丸く、かなりデフォルメした黒〜チャコールとクリーム色、立ち耳、額の特殊な星形模様。顔のサイズ・色・模様・頬や耳の輪郭・画風を維持し、リアルに寄せない。

単なる全体の上下移動に戻さない。顔を縮小して接合の問題を隠さない。頬の切り欠きを再発させない。修正には既存パーツ、マスク、ワープ、アルファ処理を優先し、全体を画像生成AIで描き直さない。

## 実装済みの内容

- 温かな部屋の縦画面UI、環境端末〈ミナト〉、ステータス、お世話、探索、夜の物語。
- 7日間の第一章と2つの選択結果。8日目以降も日々のお世話と短い夜の物語を続けられる。
- 日記、持ちもの、犬の名前変更、ブラウザlocalStorageへの自動保存、JSON書き出し・読み込み。
- 既存coreの数値ルールとprototype互換性は維持。表示用の物語は別レイヤー。
- 犬の待機、耳、しっぽ、なで反応、遊び、食事、睡眠、疲れの状態。非表示時は時間を止め、端末の動きを減らす設定では静止表示。

### 主なファイル

- `src/main.ts`: 操作画面、お世話とcoreの接続、夜の進行、日記、設定。
- `src/style.css`: 縦画面UI。
- `src/content/chapter.ts`: 表示用の第一章。
- `src/core/`: ゲームルール。既存prototypeとの等価性テストあり。
- `src/platform/save.ts`: 保存、復元、入力検証。
- `src/render/dog-motion.ts`: 実際のゲームで使うPNGモーション再生。
- `public/assets/room.svg`: 現在の部屋。
- `public/assets/dog/idle-v12/`: 首元・頬を修正した基準素材。元PNGは新しい反応追加時に変更していない。
- `public/assets/dog/motions-v1/`: 局所ワープで作成した25枚の反応PNG、`motions.json`、検証情報、6種の確認用アニメWebP。
- `scripts/make-dog-motions.py`: 素材生成と固定範囲検証。Pillow / NumPy / SciPyが必要。
- `scripts/check-playable.py`: Chromium操作・保存復元・オフライン検証。Python Playwrightが必要。ChromiumパスとURLはローカル環境に合わせる。
- `docs/playable-chapter.md`: 現在の実装と確認範囲。
- `docs/dog-idle-v12.md`: 元の首元修正と組み込みの記録。
- `docs/verification/`: 実画面・犬反応の確認画像と操作結果。

### 元の待機タイムライン

320×320 RGBA、`frame_00.png`〜`frame_11.png`。

再生順: `[0,1,2,1,0,4,5,4,0,7,8,7,0]`

時間(ms): `[1300,90,140,90,750,200,650,200,800,200,650,200,1100]`

全体6370ms。新しい待機はニュートラルの保持時間内に耳のコマを挿入し、元の瞬き・描かれた首かしげの時刻を保っている。

元のv12待機ではy=245以降の胴体下側と足が基準と同一。新しい反応はy>=245・x<224の足と胴体下側を完全一致で検証し、右側しっぽだけをその固定範囲の外で動かす。今後も足・胴体下側を安定させ、接合や顔サイズは同じ背景・サイズ・テンポで変更前後を比較する。

## 開発・検証コマンド

```sh
npm ci
npm run dev
npm test
BASE_PATH=/mofumofu/ npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

Pages用previewのURLは `http://127.0.0.1:4173/mofumofu/`。PythonとChromiumの環境を合わせたら `python scripts/check-playable.py`。WindowsではBASE_PATH環境変数の設定方法をシェルに合わせる。
