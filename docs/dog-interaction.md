# 犬の触れ合いと動きの質（2026-10-03）

`docs/local-handoff.md` の「次の完成目標」2〜4（UI・モーション・触れたときの反応の質、自己確認）への対応。
参考APK（StarDesk）とPetGameのローカルコードはこの環境から参照できないため、APKに基づく改善は行っていない。

## 方針（維持事項）
- 承認済み idle-v12 と motions-v1 のPNGは一切変更しない。新しい絵も作らない。
- 足・胴体下側（犬の絵の y>=245）は常に固定。全体の上下移動・顔の縮小はしない。
- 変形は「行ごとの小さな横ずれ・持ち上げ」だけ（局所ワープ）。

## 変更内容
| 項目 | 内容 | ファイル |
|---|---|---|
| 描画 | 犬を `<img>` から WebGL の格子（5px間隔×65行）で描画。行の境目で補間されるため継ぎ目が出ない。WebGLが無い端末は Canvas2D の帯描き、読み込み失敗時は元の `<img>` の静止画 | `src/render/dog-gl.ts`, `src/render/dog-motion.ts` |
| 呼吸 | 胸から上だけを 0.8〜2.0px 持ち上げる（状態ごとに振幅・周期を変える。眠りは深くゆっくり） | `src/render/warp.ts` |
| 首の寄せ | 触れた瞬間に指の方へ、なでている間は手を追って頭の行だけ横へ最大3.2pxずらす（臨界減衰のばね） | 同上 |
| 反応の切り替え | 140msのクロスフェード。前後のコマを画素ごとに混ぜるので、切り替え中に犬が透けない | `dog-gl.ts`（シェーダーの mix） |
| タッチ | タップ・長押し・なでる＝従来どおり「なでる」。なで始め（合計移動26px以上）からは手を追い、0.65秒ごとに指の上へハート。縦スクロールで取り消されたときは、なで始めていた場合だけ数える | `src/main.ts`, `src/render/gesture.ts` |
| 演出 | ハート（なでる）、きらめき（あそぶ・尾の近く）、器とごはんが減っていく様子（食事。狭い画面では食事中だけ部屋の説明文を退ける）、夜の「z」（暗い部屋でも読める淡色＋影）、しょんぼり時のため息 | `src/render/effects.ts`, `src/style.css` |
| 動きを減らす設定 | 犬は最初のコマを静止表示、演出は出さない（器は静止で出す） | 各ファイル |

## 確認結果
- 自動テスト：`npm test` 25件成功（追加：足の固定・帯の連続性・変形量の上限・なでる判定）。`tsc` 成功。
- ビルド：`BASE_PATH=/mofumofu/ npm run build` 成功（事前キャッシュ76件）。
- ブラウザ（Chromium・本番ビルド・390×844、タッチ有効）：
  - `scripts/check-playable.py` と同じ手順をNodeのPlaywrightで実行（この環境にPython版Playwrightが無いため）。なでる・食事・遊び・探索・保存復元・7夜→8日目・320/390/430pxで横はみ出しなし・オフライン再読み込み後のなでる、例外なし。描画は WebGL。
  - タップ→なでる（なかよし+1・あんしん+4）、なで続け→手を追う＋ハート（なかよし+1）、食事・遊び・眠りの各モーションへの切り替え。
  - 描画1回あたり約0.06〜0.13ms（PCのChromium、開発ビルドで計測）。
- 自分の目視確認（`docs/verification/dog-interaction.png`：待機／タップ直後／なで中／食事／遊び／眠り）：
  首元・輪郭に継ぎ目や横縞なし、切り替え中の透けなし、器は足先を隠しすぎない、夜の「z」が読める。
