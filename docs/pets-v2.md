# ペットの新しい見た目とアニメーション（2026-10-05）

ユーザー提供の `PetGame_Cat_Phaser_Pack` / `PetGame_Dog_Phaser_Pack` / `PetGame_Animation_Previews` を取り込み、これまでのペット（灰青色の猫のパーツ式リグ・ボーダーコリー風の犬）と差し替えた。

## 素材
- 黒白に赤い紋様の犬、白黒に青い紋様の猫。赤ちゃん／中間／成体の 3 段階 × 8 動作（待機・右歩き・左歩き・食事・水飲み・遊び・なでられる・睡眠）。768×768 のコマ画像（足元 y=690）。
- 取り込み：`python scripts/import-pets.py <猫パック> <犬パック>` → `public/assets/pets/<キャラ>/page-N.webp`・`page-N.json`・`still.webp` と `pets.json`。
  使うコマだけを詰め直し、WebP（質 96・アルファ無劣化）に変換（PNG 計約 47MB → 約 11MB）。元の画素は変えていない。
- 旧素材（`public/assets/dog`・`public/assets/pet/cat`、旧リグのコード）はリポジトリに残すが、使わない（事前キャッシュ・プレビューから除外）。

## 提供素材の不具合（解決済み）
- 最初に受け取った `PetGame_Cat_Phaser_Pack` の `cat_adult/page-0.png` が途中で切れていた（使うコマのうち 8 コマが欠落）。仮に、歩き 6 コマは左向きの反転（厳密一致を確認）、食事 2 コマは別コマで置き換えていた。
- 2026-10-05 に再アップロードされた素材では、切れていた `cat_adult/page-0`・`cat_baby/page-1`・`dog_baby/page-1` が無事になっていることを確認し（読み込める行数で検査）、全コマを原本から取り込み直した。以前の反転による復元が原本と一致していたことも確認（差 0）。復元・置き換えは使っていない。
- `animations.json` の `pages` の数が実際のファイル数と合わない（参照されないページがある）。取り込みでは参照されるコマだけを使う。`dog_baby/page-1.repaired.png`（切れたままの別ファイル）は使わない。

## 実装
- `src/render/pet-sprite.ts`：Phaser 3 のスプライトでコマ送りを再生（素材の `petAnimations.mjs` と同じ方式：フレームごとの表示時間、`frameRate: 1000`）。動作の切り替えで前のコマを 90ms 溶かす。ゲームはスロットごとに 1 つを使い回し、描き直しでは canvas を付け替える。成長段階が変わると絵を読み込み直す。
- `src/render/pets.ts`：種類×段階の寸法。犬と猫は同じ寸法（箱の幅：赤ちゃん 80／中間 72／成体 68 cqw）。足元は部屋の高さの約 77%。成長：1〜7 日＝赤ちゃん、8〜21 日＝中間、22 日〜＝成体（案。確定は第 5 段階）。
- 動作の割り当て：待機＝idle、なでる＝petted、遊ぶ＝play、ごはん＝eat（器つき）、ときどき水飲み＝drink（水の器つき）、夜＝sleep、元気がない＝idle をゆっくり・少し暗く、歩く＝walk_left/right（箱を一定の速さで動かす）。
- 歩き：床をタップするとそこへ歩く／待機中に自動で歩く／ごはんで中央の器へ歩く。歩きのコマは体が枠内で動かない（重心の揺れ 3〜10px）ので、箱を段階ごとの速さで動かして足が滑りにくいようにした（赤ちゃん 90・中間 120・成体 150 px/秒。目での調整は未実施）。
- 導入：選択画面の犬・猫は赤ちゃん。犬は近づいて（歩き）、猫は身を引く（歩き）。
