仕様の出どころ：ユーザー提供「PetGame 導入・ペット選択 コンセプト仕様書」。

## 流れ（新規の保存がないときだけ。所要はおよそ 1 分 50 秒＋選択・入力の時間）
1. 起動前の仮画面：「タップして起動」「音を出さずに起動」。最初のタップで音を使えるようにするためのもの（タイトル画面は別途決定）。
2. Scene 01：再起動と診断の記録（薄い等幅文字・左上）。
3. Scene 02：音声記録。「……お願い」→「この子を、生かして。」→ 雑音 →「記録の一部を復元できませんでした。」。**三つ目の言葉は DAY 1 では出さない。**
4. Scene 03：部屋の映像が、ぼけ・白黒・走査線の状態から段階的に復元される。
5. Scene 04：部屋の中に犬と猫。カードや説明は出さず、触れるだけ。
   - 犬：「……こちらを見ている。」→ 近づく（足音・首輪の音）
   - 猫：「……まだ警戒している。」→ 目をそらし、一瞬だけ視線を戻す
   - 「保護対象を確認しました。」→「この子を保護しますか？」［保護する］［戻る］
6. 暗転「保護対象を登録しました。」（選ばなかった方は出さない・説明しない）→「識別のため、名称を登録します。」→ 名称（8 文字まで）→「「ミケ」登録しました。」→ 中央に「DAY 01」。
7. DAY 1：「空腹を検知しました。」（ごはんのボタンが静かに光る）→ 与えると「栄養摂取を確認。生存状態：正常。」→ しばらくしてペットがこちらを見る → なでると良い反応 →「……」→「この行動に、生存上の必要性はありません。」

## 実装メモ
- 選んだ種類は保存（`species`）。導入前の保存には猫を補う。`tutorial`（feed → pet → done）も保存。
- 物語・品目の「犬」「ドッグフード」は、猫のとき表示直前に置換（`sp()`）。core の文言・数値と互換性テストは変更なし。
- 環境音は Web Audio で合成（風・唸り・電気ノイズ・軋み・息・足音・首輪）。決定音・ファンファーレなし。設定から切れる。
- スキップ（右上）：Scene 01〜03 を早送り。
- 犬のリグ・素材の事前キャッシュを復帰（`vite.config.ts` の globIgnores を元に戻した）。
