# UI・部屋の質感の刷新（2026-10-03）

ユーザー指示：以前の素材（`PetGame_DogIdle_v10.zip`）を参考に、UI・部屋の質感・グラフィックの質を上げる。

## 受け取った素材について
- zip の中身は待機アニメ v10（PNG12枚・WebP・GIF・animation.json・README）だけで、UI や部屋の素材は含まれていなかった。v10 は現在使っている v12 の前の版（頬の欠けを直す前）なので、犬の絵には使っていない。
- 参考にしたのは犬の絵柄：丸いデフォルメ、暗い茶の輪郭線、クリームとチャコール、やわらかい陰影。部屋・UIをこの画風に合わせた。

## 部屋（背景）
- `scripts/room/make_room.py` が SVG を組み立て、`render-room.mjs`（Chromium）で描いて WebP にする（`scripts/room/build-room.sh`）。
  ブラウザごとの SVG フィルター差を避けるため、アプリに置くのは焼いた WebP のみ。画像生成AIは使っていない（図形・グラデーション・ノイズだけ）。
- 朝・昼・夕・夜の4種（`public/assets/room/room-*.webp`、各 約90〜160KB）。ゲームの時間帯（朝／昼／夕／夜）に合わせて切り替える。
  以前の「色を重ねるだけ」の夕・夜は、窓の空・街の灯り・月と星・端末の光・卓上ライトの灯りまで描き分けた。
- 質感：しっくいの壁（ムラと細かな粒）・羽目板・幅木、板張りの床（板ごとの色ムラ・木目・継ぎ目・手前ほど大きい板）、
  織りと房のあるラグ、木目のある窓台と机、段ボール（波目・テープ・「配給」の札）、カーテンのひだ、窓の十字に落ちる光、壁ぎわと手前の明暗、
  周辺の減光と粒子。
- 小物：止まった壁掛け時計、付箋、ミナトの端末（走査線・波形の光・LED）、本、卓上ライト、窓台の鉢植え、水の器、足元のケーブル。
- 犬の足元の影を背景側に描いた（犬の絵は影を持たないため）。犬の表示幅は 88%→80% にして、部屋が見える面積を増やした。

## UI
- 文字：見出しは明朝系（端末の明朝／Noto Serif JP）、本文はゴシック。
- 部屋カード：二重の縁取りと影。日付・時間帯・端末名・ひとことは、半透明のぼかしのチップにして背景の上でも読める。夜は暗色のチップ。
- 状態：カードにまとめ、四つの値を色分け（おなか＝琥珀、げんき＝若草、なかよし＝桃、あんしん＝水色）。バーはグラデーション。
- 操作ボタン：丸い印の飾りつき、押し込みの動き。「今日を終える」「ナビ」の選択中は押し込み風。
- 面：和紙のような微粒子の背景、カードの影、ダイアログの紙質・ボタンのグラデーション。
- 色・影は CSS 変数（`--card`、`--shadow` など）に集約。
