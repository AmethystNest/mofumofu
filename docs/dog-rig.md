# パーツ式の犬（Phaser 3 の Container と Tween）（2026-10-03）

ユーザー指示：HTML5＋Phaser 3 で、Container の親子関係と Tween により、体の動きに耳・髪・目・尾・手足が遅れて追う
「フォロースルー」、縦伸び・横つぶれの「もちもち感」、自動のまばたき・視線を実装する。

## 使ったもの
- **Phaser 3.90.0**（3系の最終版・MIT）。npm の `latest` タグは Phaser 4.2.1 だが、指定どおり 3 を使用。
- **CDN ではなく npm で同梱**し、`import('phaser')` で遅延読み込み（別チャンク 約1.2MB／gzip 約320KB。初期の本体は 43KB のまま）。
  理由：このゲームは PWA でオフライン動作が必須。CDN だと初回以外の読み込みや更新が外部依存になる。Service Worker の事前キャッシュに含めてある。
- Phaser が使えない端末では、従来の一枚絵の描画（`dog-motion.ts`）に自動で切り替わる。

## 絵の扱い
- 承認済みの待機絵 `idle-v12/frame_00.png` は**変更しない**。`scripts/cut-rig.py`（Pillow・numpy・scipy）で、元画像の画素だけを使って
  派生素材 `public/assets/dog/rig-v1/`（atlas.png / atlas.json / rig.json）を作る。画像生成AIでの描き直しはしていない。
- **しなるパーツ（Phaser の Rope）：耳（左右）・ほほ毛（左右）・しっぽ。** 付け根は動かさず、先へいくほど大きくしなる（回転ではない）。
  切り口が動かないので継ぎ目が出ない。切り口の側は 4px だけ広げてベースと重ね、細い隙間（半透明の縁どうしの合成）を防ぐ。
- **目：重ね合わせをやめ、「目まわりのシール」1枚にした。** 開き目は元の絵、半目・閉じ目は承認済みの別コマ（`idle-v12` の frame_01 / frame_02）の
  同じ範囲を位置合わせして切り出したもの。シールの下のベースは、目のまわりの毛・クリーム色を最も近い色で埋めてある。
  まばたきは開き→半目→閉じ目の順に重ね、視線はシールごと最大 約±2px ずらす。
- 前足は別パーツにしていない（輪郭が隣の足と一体で、切ると切り口が見えるため）。
- **安静姿勢で重ねると元の絵に戻る**：`python scripts/check-rig-rest.py`（色差は最大でも約10／255、7画素）。

## 動きの作り
| 層 | 内容 | ファイル |
|---|---|---|
| 親（体） | `root` Container を床の1点（160,287）で支え、Tween で上下・縦横の伸び縮み（面積を保つ `squashX`）・傾き・呼吸 | `dog-rig.ts` |
| 子（フォロースルー） | 体の「頭のてっぺんの速さ」から目標のしなりを計算し、行き過ぎて戻るばね（`Spring`）で追わせる。耳（フロッピー）・しっぽ・ほほ毛（横になびく）・目のシール（視線＋遅れ） | `dog-rig.ts`, `rig-math.ts` |
| もちもち | ぴょんぴょん＝ため（つぶれ）→跳ぶ（伸び）→落下→着地（つぶれ）→弾んで戻る（Elastic）。なでると小さく弾み、閉じ目（^^）になる | 同上 |
| 生きている感じ | まばたき（2.2〜5.5秒おき・18%で二度）、視線のキョロキョロ（1.3〜3.8秒おき・たまに反対側も）、耳ぴく（音のほうへ視線）、しっぽの短い速い振り、ふとした首かしげ（体を傾け耳が遅れて追う） | 同上 |
| 専用コマ | 食事・眠り・しょんぼりは座り姿勢から大きく変わるため、承認済みの専用コマ（motions-v1）をそのまま使い、体の伸び縮みと呼吸を重ねる | 同上 |

- 画面の描き直し（お世話のたびに起こる）で Phaser を作り直さない。ゲームは1つだけ作り、canvas を付け替える（外している間は更新停止）。
- 「動きを減らす」設定：静止した安静姿勢（専用コマの状態ではそのコマ）。更新も止める。

## 確認結果
- 自動テスト（`npm test` 41件成功）：ばね（収束・行き過ぎ・フレーム飛び）、スクワッシュの面積保存、視線の範囲、素材の整合（枠・向き・目のシールの位置）。
- ブラウザ（Chromium・本番ビルド）：既存の通し確認（なでる・食事・遊び・探索・保存復元・7夜→8日目・320/390/430px・オフライン再読み込み）は
  すべて通過、描画は Phaser の WebGL、例外なし。動きを減らす設定でも静止表示と状態切り替えが正常。
- 自分の目視（スクリーンショット・3倍）：
  - `docs/verification/dog-rig-poses.png`：安静・耳（外／内／はね上げ）・しっぽ（±8px）・半目・閉じ目・視線（左右上下）・傾き・伸び縮みを固定して撮影。
  - `docs/verification/dog-rig-idle.png`：待機を0.33秒おきに30コマ（まばたき・視線・耳ぴく・首かしげが自然に起こる）。
  - `docs/verification/dog-rig-play.png`：安静・なでる・遊ぶ・食事・眠り（本番ビルド）。
  - 食事への出入り（座り⇔専用コマ）を14＋16コマで確認。耳・しっぽ・頭まわりの切れ、目の二重線は見当たらない。
  - 初版で出ていた不具合（目の縁・まぶたの重なり、耳の付け根の線、しっぽ付け根の段差、前足の四角い切り口、パーツ境の縦線）は上記の作りに変えて解消。

## 既知の制約・未確認
- 元が一枚絵のため、パーツの裏側の絵は無い。耳・ほほ毛・しっぽのしなりは数px（先端）に抑えてある。大きく振ると継ぎ目が出るため。
- 目は半目・閉じ目が承認済みの別コマの絵（閉じ目は ^^ の形）。普通のまばたきも ^^ になる。目の視線は約±2pxと小さい（目が大きく、黒目が輪郭に接しているため）。
- 「髪」はほほの毛束のみ。前足・後ろ足は別パーツにしていない（足は体といっしょに伸び縮みする）。
- 承認済みの待機ループ（6370ms・首かしげのコマ）は、パーツ式の待機（視線・まばたき・傾き）に置き換わっている。従来描画は代替として残してある（WebGL が使えない端末）。
  食事・眠り・しょんぼりは専用コマなので、まばたきや視線は出ない。
- 座りと専用コマの切り替えは短いクロスフェード（約0.1秒）。Android・iPhone 実機でのFPS・見た目は未確認（検証は PC の Chromium のソフトウェア描画）。
- ユーザーの評価は未確認。
