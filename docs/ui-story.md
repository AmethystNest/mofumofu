# UI の洗練と物語の進め方（2026-10-06）

導入・ペット選択のコンセプト仕様書（半透明・細い文字・小さなシステム表示・派手なボタン／大量のアイコン／ステータスカードの禁止、感情を説明しない、認識が少しずつ変わる）を、導入だけでなく本編の UI と物語にも通した。

## UI（`src/styles/`・`src/main.ts`・`src/ui/scene.ts`）
- **見た目の約束**：暗い背景・細い文字（ゴシック／等幅／明朝の3種）・1px の仕切り線。旧版の和紙調のクリーム色のカード・丸いアイコンボタンは全廃。色は薄い水色（システム）とごく淡い橙（弱っている値）だけ。
- **ホーム**：上に `DAY 07 朝 ミケ` と「記録・備蓄・設定」。その下に細い線だけの状態の帯（満腹・活力・信頼・安定｜電力｜行動）。数値・カードは出さない。下はシステムの記録の末尾（新しい行ほど濃い）と、アイコンなしの操作の帯（給餌・接触・遊戯・外出・休止。行動の消費は小さな点）。
- **シート**（給餌・外出・休止の確認・設定）：下から出る暗いガラス。**記録・備蓄**は画面いっぱいの暗い面。
- **場面**（`ui/scene.ts`）：夜の記録・DAY の切り替え・復元された記録は、暗転の上に薄い文字を重ねる。下の部屋とペットがぼんやり透けて見える。画面をタップすると、表示中の文を待たずに先へ進む（読む速さに合わせる）。
- **導入と同じ言葉づかい**：システム側の言葉（給餌／接触／遊戯／外出／休止、満腹／活力／信頼／安定／電力）。主人公の体力は「電力」、食料を自分に回す操作は「予備電池へ」（食料と予備電池の複合パックという設定）。核の数値・規則は変更なし。
- 窓の広い画面（PC）では、幅 560px の中央の枠に収める。

## 物語（`src/content/story.ts`）
- 声：家庭に置かれていた生活管理システムの記録。事実から短く書き、感情を説明しない。主人公の正体・世界が壊れた原因・飼い主の生死・期間は書かない（テストで禁止語を検査）。
- 認識の段階（日数）：**0（1〜7日）** 生存に必要かどうか／対象・識別・登録の言葉 → **1（8〜14日）** 好み・安定、名称を識別以外に使い始める → **2（15〜22日）** 記録すること自体が目的に近づく、成体になる → **3（23日〜）** 「保護対象」の表記が合わなくなる。ホームの一言（給餌・接触・遊戯・外出・朝）も段階で変わる。
- 1〜7日は核の夜イベント（n1〜ch1）に対応（選択肢の順番は核のまま。登録の選択は「共同配給所」）。8〜29日は日ごとの記録、31日目以降は静かな日々が巡る。
- 音声記録：DAY 1 の「……お願い」「この子を、生かして。」が、10・17・24日目の再検査で復元率 41→62→83%（背景音＝玄関の扉と複数の足音）まで戻り、**30日目に完全に復元**される。続きは「……それから、あなたも。」→「生きるって、ただ息をすることじゃないから。」。そのあと「「保護対象」。この表記は、現在の状態に適合しません。」「ミケ。」で結ぶ。DAY 1〜29 には「それから、あなたも」を出さない（テストで検査）。
- 夜の流れ：休止（確認）→ 暗転「休止処理を開始します。」→ その日の維持項目（段階が進むと減る）→ 夜の記録（必要なら選択）→ 結果 → 「DAY 08」→ 朝。

## 文字の読みやすさの修正（2026-10-06、ユーザー指摘「ボタンがほぼ見えない」）
- 原因（推定・高い確度）：文字の太さを 300（細字）にしていた。確認に使っていた環境には日本語の細字フォントがなく、普通の太さで表示されていたため見落とした。Android の日本語フォント（Noto Sans CJK）には細字があり、そのとおり細く薄く出ていた。
- 対策：細字を廃止（本文 400、ボタン・見出し 500）。文字を 1〜2px 大きく、色を明るく（薄い文字 #a6b8c2 → #cbd7dd 等）。操作の帯は 16px・白、記録／備蓄／設定は縁取りのある丸いボタンに。導入の「タップして起動」「保護する／戻る」なども同様。`color-scheme: dark only` を指定し、端末側の自動ダーク化で色が反転しないようにした。
- 確認：Noto Sans JP（細字を含む可変フォント）を入れた Chromium で、公開用ビルドを 360×760・390×844 で撮影（ホーム・給餌・記録・休止の確認・夜の場面・選択、導入の起動・選択・名称・DAY 01）。`docs/verification/ui/after-*`、`docs/verification/intro/after360-*`。

## 言葉のバランス（2026-10-06、ユーザー指摘「全部漢字だと中国風」）
- 操作：ごはん／なでる／あそぶ／外出／休む。状態：おなか／げんき／信頼／安心／電力／行動。メニュー：記録／持ちもの／設定。品目：配給セット／缶詰／ペットフード。
- システムの記録の文（夜の場面・ホームの一言）は、導入と同じ硬めの言い回しを残しつつ、「給餌」「接触」「遊戯」などの漢語は「ごはん」「なでた」「あそび」に置き換えた。
