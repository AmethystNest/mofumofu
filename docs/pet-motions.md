# ペットの動きの追加と大きさの統一（2026-10-04）

## 大きさ
- 犬と猫の画面上の大きさを、絵の見えている面積と高さがほぼ等しくなるよう合わせた（猫＝部屋の幅の約 37.9%：既存の指定比率。犬＝箱の幅 49%。面積差 約 4%、高さ差 約 4%）。
- 導入の選択画面でも、犬・猫に同じ倍率（0.68）を使う。足元の高さは両方とも部屋の高さの約 77%。
- **描画のタッチ**：犬・猫ともユーザー提供・承認済みの絵（どちらも太めの暗い輪郭と平塗りのちびキャラ）で、元のPNGは変更していない。同じ画風へ描き直すことはしていない（画像生成AIは使わない方針）。大きさ・足元・影・動かし方（共通の動きの部品）は揃えたが、毛のぬりと輪郭の描き方の違いは残る。

## 動き（犬・猫共通。`src/render/gaits.ts`・`src/render/wander.ts`）
| 動き | 内容 |
|---|---|
| 歩く（walk） | 一歩ごとの沈み・伸び・着地、左右に傾く、しっぽが立つ。箱ごと横へ移動（速さは部屋の幅の約13%/秒、30〜70% の範囲） |
| のび（stretch） | しゃがんで伸び上がり、目を閉じて止まり、戻る |
| ぶるぶる（shake） | 目を閉じ、体を細かく振り、耳がはためく |
| くんくん（sniff） | うつむき、小さく上下しながら左右を嗅ぐ |
| 食べる（eat） | 既存。離れた場所にいるときは、器のある中央へ歩いてから食べる |

- 自動：待機中に 9〜21 秒おきに歩き、14〜26 秒おきに「のび・ぶるぶる・くんくん」のどれかを挟む。
- 操作：部屋の床（画面の下 4 割）をタップするとそこへ歩く。なでると、歩きを止めてその場でなでられる。
- 「視差効果を減らす」設定では歩かず、仕草も出さない。WebGL が使えない代替表示では、歩く＝弾む、その他＝待機。
- 横位置は画面の描き直しをまたいで覚える。

## 確認範囲
- 実行確認（Chromium・390×844・2倍）：犬・猫それぞれで、床タップ→歩行、のび・ぶるぶる・くんくん、ページエラーなし（`docs/verification/anim/`、`scripts/walk-shots.mjs`）。
- 未確認：実機。動きの「感じ」（速さ・間）は静止画の連続でしか見ていないので、実際の動きは触って確かめてほしい。
