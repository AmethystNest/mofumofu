# 灯りの残る部屋 — プレイ可能な第一章

縦画面PWAの紹介用仮画面を、実際にお世話・探索・夜を進められる画面へ置き換えた。災害後の静かな近未来の街、温もりのある小さな部屋、犬との生活を中心にする。人間や猫の絵は追加していない。

## 遊べる内容

- ごはんを犬・自分・半分ずつに分ける。なでる、あそぶ、3地点の探索。行動力・所持品・体力・犬の状態を既存coreと接続。
- 7日間の第一章と2種類の選択結果。以後も日々のお世話と短い夜の物語を続けられる。
- 日記、持ちもの、犬の名前変更、端末内自動保存、JSONバックアップ・読み込み。再読み込み後も未完了の夜から再開できる。
- 食事や探索などの数値ルールは既存prototypeと同一。新しい物語は表示層で管理し、既存coreの互換性を保った。

## 犬の追加モーション

承認済み `idle-v12` の12枚を変更せず、同素材の局所ワープから25枚を新規作成。耳・しっぽの境界は、切り離したレイヤーの重ね合わせではなく滑らかな座標変形に修正し、分割による白い隙間や二重の輪郭をなくした。

待機に左右の耳の動き、なでた時の閉じ目としっぽ、遊びのしっぽ、食事の小さな首の動き、睡眠、疲れの状態を追加。顔の縦横比を縮小しない。元の瞬き・描かれた首かしげの時刻、全体6370msのテンポは維持。新規フレームのy>=245・x<224の足と胴体下側を基準フレームとの完全一致で検証。右側しっぽのみこの固定範囲の外で動かす。

`python scripts/make-dog-motions.py` でPNGとmanifest・固定範囲検証・一覧画像を再生成（Pillow / NumPy / SciPyが必要）。WebPは確認用、実際のゲームはPNGタイムラインを使う。非表示時は時間を止め、端末の動きを減らす設定では静止表示。

## 確認結果と限界

- unit / simulation / prototype equivalence: 18テスト成功。符号付き乱数状態の保存復元、不正保存の拒否、第一章両分岐、素材参照・タイムラインを含む。
- GitHub Pages用 `/mofumofu/` production build成功。
- Chromiumで390×844の実操作: なでる・食事・遊び・探索・睡眠・保存復元・未完了の夜の再開・7夜を経て8日目へ到達。日記生成を確認。
- 320 / 390 / 430pxで横はみ出しなし。PWAオフライン再読み込み後も犬の反応が動作。ブラウザ例外なし。
- 同じサイズの反応一覧と実画面のスクリーンショットを目視確認。足の固定、耳根元・しっぽの接合、首元、表情を確認した。初回の分割境界の欠けは修正済み。

実行確認は見た目のユーザー承認とは別。iPhone / Galaxy実機、Safari固有の挙動、ユーザーによる見た目評価は未確認。保存は端末内だけで、ブラウザデータ削除時に消えるためバックアップ機能を提供。クラウド同期、第二章の新しい連続ストーリーは実装していない。
