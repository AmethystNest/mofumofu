# ペットを猫に、部屋を新しい背景に差し替え（2026-10-04）

ユーザー指示：提供された猫の絵と4枚の部屋の絵に差し替える。合成図の比率（猫は部屋の幅の約38%）が理想。部屋の物は模様替えで置くので、最初は無くてよい。

  ゲームの時間帯（朝・昼・夕・夜）に合わせて切り替える。合成図は昼の部屋。
- 前の部屋（自作SVG→WebP）と生成スクリプト、`room.svg` は廃止した。

## 画面
- 部屋を**画面いっぱい**の舞台にした（`.stage` / `.scene`）。部屋の絵の比率（941:1672）を保ったまま画面を覆い、はみ出す側は中央を残して切る。
- 猫の配置は合成図に合わせた：幅＝部屋の幅の37.9%、左端31.0%、足元＝部屋の高さの76.9%。
  確認：画面と同じ比率で重ねた画像（`docs/verification/cat-ratio.png`、左がユーザーの合成図／右がこの実装）で位置・大きさが一致。
- 見出し・状態（おなか／げんき／なかよし／あんしん）・行動力はガラス状の面で部屋の上に重ねた。操作ボタン5つ（ごはん／なでる／あそぶ／さんぽ／ねる）と下のナビ（おへや／日記／もちもの）は下に置いた。
- 背の低い画面（高さ800px以下）では、猫の足元に操作が重ならないよう、ひとことを上へ移しボタンを詰める。
  確認：320×568、360×640、390×844、430×932、768×1024 で横はみ出しなし・猫に操作が重ならない。
- 日記・もちものは、これまでの紙の画面のまま。

## 猫の動き（Phaser 3）
- 切り出し：`scripts/cut-cat.py` が猫のPNGから、耳（左右）・しっぽ・目まわりのシールを切り分ける（`public/assets/pet/cat/rig/`）。元PNGは変更しない。
  安静時に重ねると元の絵に戻る（`python scripts/check-cat-rest.py`、色差は最大7.6／255）。
- 耳としっぽは、付け根を固定してしなる Rope（犬のときと同じ方式。回さないので継ぎ目が出ない）。
- 目：開き目（元の絵）に、半目・閉じ目（‿）・笑い目（^）を重ねて切り替える。後ろの3種は、元の線の太さ・色に合わせてコードで描いた線と、目のまわりの毛の色で作った（画像生成AIは使っていない）。
- 動き（`src/render/pet-rig.ts`）：
  - 待機：呼吸、まばたき、キョロキョロ、耳ぴく、しっぽ、ふとした首かしげ。
  - なでる：笑い目で弾み、しっぽを振る。
  - あそぶ：ぴょんぴょん（ため→跳ぶ→着地）。
  - ごはん：もぐもぐ。
  - 眠り：目を閉じて低く、ゆっくり息をする。
  - しょんぼり：半目で、耳としっぽが垂れる。
  - 体は床を支点に伸び縮みし、耳としっぽが遅れて追う（ばね）。
- Phaser（WebGL）が使えない端末は、一枚絵に CSS のゆらぎを付ける代替表示。「動きを減らす」設定では静止。
- 犬の素材・コード（`public/assets/dog/`、`src/render/dog-*.ts`、`warp.ts` など）は残してあるが、ゲームでは使わない（事前キャッシュからも外した。事前キャッシュは 5.7MB→3.7MB）。
